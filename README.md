
# Day 30 Internship Project: Custom 404 Error Page

## Project Overview

The Custom 404 Error Page is a responsive webpage developed using HTML5 and CSS3. It displays a friendly message when a requested page cannot be found.

The page includes a large 404 heading, a space-themed CSS illustration, animated decorative elements, and a button that links back to the homepage.

## Objectives

- Practice webpage layout and typography.
- Create a centered and responsive error page.
- Design a simple illustration using CSS.
- Use CSS animations and transitions.
- Provide a clear navigation link back to the homepage.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS animations and transitions
- Media queries

## Features

- Modern dark space-themed design.
- Large and readable 404 error heading.
- Friendly error message.
- CSS-based planet illustration.
- Floating and twinkling animations.
- Back to Home button.
- Responsive layout for mobile and desktop.
- Hover effect on the navigation button.
- Reduced-motion accessibility support.
- No JavaScript, API, or database required.

## Project Structure

Day_30_Custom_404_Page/
- index.html

## How to Run

1. Create a folder named Day_30_Custom_404_Page.
2. Create the three files listed in the project structure.
3. Paste the appropriate code into each file.
4. Save all files.
5. Open index.html in a modern web browser.
6. Click the Back to Home button to test navigation.

You can also open the folder in Visual Studio Code and use the Live Server extension.

## Working Procedure

The HTML file defines the structure of the error page, including the header, illustration, error message, homepage link, and footer.

CSS is used to center the content, style the text, create the planet illustration, and add animations. Flexbox helps arrange the page elements, while media queries adapt the design to smaller screens.

The Back to Home button links to index.html, which serves as the demonstration homepage in this project.

## Testing

- Checked that the 404 heading and friendly message display correctly.
- Verified that the CSS illustration appears correctly.

- Tested the Back to Home link.
- Checked the layout on desktop and mobile screens.
- Verified that the page works without JavaScript or a database.

## Limitations

- This is a static demonstration page.
- The homepage link points to index.html and does not automatically detect the real website homepage.
- The page does not handle server-side HTTP 404 responses by itself.
- The selected Google Font requires internet access; fallback fonts are provided.

## Future Scope

- Integrate the design with a website's actual 404 route.
- Add a search box to help users find pages.
- Include links to popular website sections.
- Add a contact or support link.
- Track broken-page visits using website analytics.

## Conclusion

The Custom 404 Error Page project demonstrates how HTML5 and CSS3 can be used to create a visually appealing and user-friendly error page. It provides practical experience with layout design, typography, CSS illustrations, animations, transitions, and responsive web design.
